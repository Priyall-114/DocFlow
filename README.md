# DocFlow — File Management REST API

A secure backend REST API for file management built with Spring Boot.

## Tech Stack
- Spring Boot, MongoDB Atlas, JWT
- AWS S3, AWS Elastic Beanstalk
- Razorpay Payment Gateway

## Features
- File & Folder CRUD with inline viewing
- JWT Authentication with refresh token rotation
- Storage quota system (100MB default)
- Razorpay payment integration for storage upgrades
- AWS S3 cloud file storage
